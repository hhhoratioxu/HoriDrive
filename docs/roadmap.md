# 阶段验收与后续工作

| 阶段 | 本次实际实现 | 仍待验收 / 完善 |
| --- | --- | --- |
| 1 基础工程 | 六模块 Workspace、SQLite、Tauri / React、日志与默认关闭接收端 | 生产日志轮转与安装升级迁移 |
| 2 本地文件 | 浏览、导入导出、目录、复制移动、回收站、搜索、图片 / 文本预览、拖拽入口 | 大规模 UI / 可访问性验收 |
| 3 设备通信 | QUIC mTLS、证书指纹配对、系统凭据、撤销、手动 IP、mDNS、双进程真实传输 | 第二台物理机器 / 不同网络配置验收 |
| 4 同步引擎 | notify、向量时钟、双向同步、tombstone、冲突副本、分块校验与断点重试、CLI 周期重连 | 桌面后台重连、多同步根、自适应并发、复杂目录并发拓扑压力测试 |
| 5 私人云盘 | 远端目录浏览、按需下载到本地、离线缓存、接收端存储配额 | 独立主节点模式配置、多卷管理、缓存淘汰、远程文件写操作 UI |
| 6 高级功能 | 20 版本历史、恢复、CAS 去重、清理、取消、按块限速、实时任务统计、主题 | 1 / 2.5 Gbps 基准、全局限速、性能调优、更多空间与权限故障注入 |
| 7 开源发布 | MIT、源码、说明、贡献与安全文档、Windows 本机包、Windows / macOS 工作流 | 各平台运行验收、代码签名、macOS notarization、移动端 |

上述阶段均有实际实现，但整套产品未达到全部需求的正式验收标准。特别是私人云盘模式和高级性能功能仍是基础能力，不应称为已完成的正式产品。任何 Release 只包含已实际生成的文件，并明确构建方式与未完成事项。
