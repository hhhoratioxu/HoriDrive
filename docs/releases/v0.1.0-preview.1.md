# HoriDrive 0.1.0 Preview 1

**Your Cloud. Your Rules.**

首个可运行的开发预览版：真实本地文件管理、Windows 桌面客户端、独立后台节点及双向 QUIC 文件同步。

## 已提供

- 本机文件浏览、导入导出、目录 / 复制 / 移动 / 重命名、回收站、搜索、文本与图片预览。
- 系统凭据保存设备私钥；公开证书交换、完整指纹核对、双方授权、mTLS 连接与撤销。
- BLAKE3 4 MiB 分块、完整性检查、向量时钟、并发冲突副本、tombstone、崩溃安装恢复。
- 中断 / 取消后复用已校验分块、限速、任务统计、20 版本历史和自动替换备份上限。
- mDNS 局域网发现、手动 IP / 域名、已配置的 Tailscale 网络；远程目录与按需下载、离线访问缓存。

## 使用条件

Windows 11 x64 需要 WebView2；macOS 构建包是否提供以及验证程度，以资产列表和 docs/testing.md 的实际构建记录为准。所有包目前未签名，未做独立安全审计。公开证书必须独立核对完整指纹；局域网接收需显式指定地址，并由用户自行管理防火墙。

文件与数据库没有静态加密。已信任设备可访问整个空间。仍需独立备份。

## 预览版边界

移动端、NAT 穿透、托盘 / 自启动、桌面自动重连、多存储卷、自适应并发及 1 / 2.5 Gbps 性能验收尚未完成。CLI `serve --interval` 支持周期同步；桌面使用手动同步。私人云盘提供远程列表与下载基础能力，尚未形成完整多卷主节点产品。

Windows 自动化实际验证了 1.004 GiB 文件、真实双进程同步、并发冲突、删除恢复、接收进程与下载进程中途终止、分块续传、取消、路径与 junction 检查、哈希错误、版本 / 备份上限、mDNS 真实公告发现。macOS 运行与系统凭据体验仍需物理设备验收。
